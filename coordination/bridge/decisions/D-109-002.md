## Decision

Use one Git-backed file protocol in `coordination/bridge/` as the canonical
coordination contract. It is not a separate bridge-agent: all participants
write task, handoff, evidence and decision changes through this protocol.

A future agent facade or command is optional. An MCP facade is also optional;
neither is the source of truth or a phone runtime dependency.

## Disposition

This architecture decision does not close T-109 acceptance. T-109 remains
`BLOCKED` because the required named runtime gates for independent `reviewer`
and `verifier` acceptance are not satisfied. No `PASS` or `closed` status is
inferred from this decision.
